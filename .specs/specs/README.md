# Shaped Specs

Output of `/spec-shape`. One folder per shaped piece of work, named
`YYYY-MM-DD-HHMM-<feature-slug>/`, holding `plan.md`, `shape.md`, `standards.md`,
`references.md` and any `visuals/`.

A spec here is a plan that was agreed before implementation started. It is not a
standard and it is not a milestone — it is the reasoning that produced them, kept
so a later session can see why the work is shaped the way it is.
