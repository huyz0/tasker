# Auto Milestone Delivery

**Delegate**: `.agents/skills/milestone-deliver/SKILL.md`
**Action**: Read and execute standard instructions exactly in AUTONOMOUS mode. DO NOT ask questions. Implement, verify, record and commit each task in sequence until the milestone closes or a task blocks.
**Argument**: Optional milestone id (e.g. `M03`). Defaults to `active_milestone` in `.milestones/STATE.md`.
