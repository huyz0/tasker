# M56-T01 registration and external-worker UX review

Independent review approves the proposed flow and its reuse of existing fonts,
type hierarchy, semantic ink/surfaces and violet action emphasis. No visual
rebrand is justified by this task. Register agent correctly describes an identity,
while external configuration and verified-at describe separately observable work.
No worker-running, installation or continuing-liveness claim is introduced.

One shared connection section outside virtualized rows keeps the next step
reachable for newly returned and existing identities. Once-only heading focus,
originating-control/heading return, no-role guidance and scoped non-secret draft
retention form a coherent navigation policy. Role instructions/capabilities are
explicitly distinguished from token API scopes.

The one-time panel keeps selectable plaintext out of live announcements and
visible configuration previews. Secret-bearing copy requires an explicit action;
copy failure retains manual access. Verification leaves copy/dismiss available,
shows the actual matching identity/time and explains that its request updates
token last-use metadata. Dismissal, replacement, logout and scope changes retire
secret/result/focus intent without reopening an old panel.

Loading/denied token administration, failed issuance, lost-secret guidance,
revoked/expired metadata and verification refusal/offline/unexpected identity are
specified. Both-theme375/768/1280 keyboard/rendered evidence remains required.
This approves proposed design only; no implementation or runtime gate is implied
complete. No implementation files or services were changed by this review.
