# Claim-history rendered evidence

The associated, owner-purged and long-owner previews use synthetic Storybook
fixtures. The real-* captures use an isolated local backend/database and actual
human, CLI and MCP operations. They contain no credentials or private production
data. Themes are applied through the actual data-theme attribute.

- associated-mobile-dark.png and associated-desktop-light.png show the receipt
  filter, bounded history and independent report sources.
- owner-purged-mobile-light.png shows factual ownership closure without an
  invented completion status; long-owner-mobile-dark.png checks text wrapping.
- real-associated-* records the first successful actual worker/report journey.
- real-eventless-unassignment.png preserves the observed stale-assignee defect.
- real-eventless-reconciled.png records the corrected older-page ownership
  refresh with Summary draft/focus retained. This predates the separate removal
  of impossible human agent-note mutation controls.
- real-readonly-* records the final human read-only note boundary and keyboard
  report filtering at375/768/1280px in both themes.

Before captures are diagnostic evidence, not the final interaction contract.
